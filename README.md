Add honeypots, math challenges, or invisible stored tokens to CakePHP forms. Stored tokens support timing checks and single-use verification; an admin interface provides inspection and cleanup tools.

Read the [CakePHP 6 branch documentation](docs/guide/index.md), starting with
[Installation](docs/guide/installation.md) and [Getting started](docs/guide/getting-started.md).
This development branch requires PHP 8.5. The
[published website](https://dereuromark.github.io/cakephp-captcha/) describes CakePHP 5.

Try the [demo](https://sandbox.dereuromark.de/sandbox/captchas).
