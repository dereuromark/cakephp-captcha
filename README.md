Add honeypots, math challenges, or invisible stored tokens to CakePHP forms. Stored tokens support timing checks and single-use verification; an admin interface provides inspection and cleanup tools.

See the [documentation website](https://dereuromark.github.io/cakephp-captcha/) for [installation](https://dereuromark.github.io/cakephp-captcha/guide/installation), [getting started](https://dereuromark.github.io/cakephp-captcha/guide/getting-started), and the full reference.

Try the [demo](https://sandbox.dereuromark.de/sandbox/captchas).
